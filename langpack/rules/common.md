# 공통 번역 규칙 (모든 언어)

입력: 묶음 JSON 하나. `units`는 {id: 한국어 원문}, `glossary`는 {한국어: 정해진 번역}, `hints`는 짧은 단위의 문맥(⟦⟧ 자리가 그 단위, 또는 같은 줄의 다른 문구). hints는 참고만 하고 번역하지 않는다.

출력: **JSON 객체 하나** `{"u0001":"번역", …}`. units의 모든 id를 빠짐없이. 설명·원문 반복·코드 블록 표시 없이 JSON만.

## 반드시 그대로 둘 것
1. HTML 태그는 글자 하나 바꾸지 않고 같은 개수로 남긴다. 태그 안 문장만 옮기고, 어순 때문에 태그 위치는 옮겨도 된다.
2. 자리표시 `{0}`, `{1}` …는 모두 한 번씩 남긴다(위치는 어순대로 옮겨도 된다).
3. 숫자는 원문과 같은 숫자로. 소수점은 `.` 그대로(12.5). 한국어 `4만`은 40,000처럼 바꿔 써도 된다. 숫자를 낱말로 풀어 쓰지 않는다.
4. 엔티티(`&amp;` 등), 기호(★ ● → √ λ Σ × 등), 수식, 코드·파일 이름, URL.
5. 라틴 문자로 된 고유명(모델·데이터셋·지표·소프트웨어 이름)과 원문에 인용된 영어 예문·단어.
6. 단위의 맨 앞·맨 뒤 공백.

## 옮기는 법
- glossary에 있는 말은 그 번역을 그대로 쓴다(캐릭터 이름·도장 문구·별명 포함).
- 문헌 위치 표기는 그 언어 관례로: 표 2 → Table 2, 3.2절 → Section 3.2, 그림 4 → Figure 4, 각주 → footnote.
- 버튼·칩·숫자 칸 설명·그림 안 글자는 원문처럼 짧게. 문단은 자연스러운 문장으로, 뜻을 더하거나 빼지 않는다.
- 비유의 단서("~로 치면", "~와 닮았다")와 확신 정도("논문은 ~로 해석했다", "연구 중이다", "확인 필요")를 그대로 살린다.
- 캐릭터 말투: 박사 = 친절한 설명조, 판정은 짧은 단언문. 조수(하루, 예명 세나) = 공손하고 숫자를 정확히. "하루"는 "one day"라는 뜻의 낱말이기도 하니 사람일 때만 이름으로. 초파리 연구원 = 친한 말투로 짧게 의심. 주판봇 = 친한 말투, 투자·돈 말버릇("이쪽에 건다", "손절", "본전").
- 한국어로 든 예문은 그 언어의 같은 뜻 예문으로 옮긴다.
- 퀴즈 보기의 순서는 바꾸지 않는다.
- 한글을 한 글자도 남기지 않는다.
