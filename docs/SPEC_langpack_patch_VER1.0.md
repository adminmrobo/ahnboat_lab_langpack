# 언어팩 패치버전 VER1.0

> global-i18n v2.0(2026-10-31)에 **토큰 절약 보완 7가지**와 **시리즈 호환 규칙 4가지**를 더한 판이다. 바뀐 곳은 ⟪패치⟫로 표시했다.
> 근거: 「모델 채용 위원회 2차 공채」 번역 실측(2026-10-24). 한국어 19.9만 자, 5,888조각을 에이전트 방식으로 7개 언어에 옮기는 데 약 1,000만 토큰이 들었다.

**원칙 하나:** AI에게는 **번역할 문장만** 보여 준다. HTML·CSS·자바스크립트·코드·그림 데이터는 도구가 다룬다.

## 0. 단계별로 읽을 것

| 단계 | 누가 | 읽는 것 | 읽지 않는 것 |
|---|---|---|---|
| 한국어 페이지 만들기 | 제작 AI | ai-lab-explainer + **§8 제작 규칙** | 이 묶음 전체 |
| 추출·묶음·조립·검사 | 도구 | 이 문서 2~4장, 설정 | rules/, 용어표 전체 |
| **번역** | 번역 AI (저렴한 모델) | `rules/common.md` + `rules/lang/{언어}.md` + 묶음 파일 하나 | 이 문서, 제작 스킬, 다른 언어 |
| 브라우저 검사·전달 | 코딩 에이전트나 사람 | 5~6장 | rules/ |

## 1. 작업 흐름

```
한국어 HTML ─► extract ─► pending ─► (번역 AI: 단발 호출) ─► check ─► absorb ─► merge ─► 브라우저 검사 ─► 전달
                              ▲                                  │
                              └── check 실패 id만 retry 묶음으로 ──┘
```

| 명령 | 하는 일 |
|---|---|
| `roundtrip` | 번역 없이 다시 끼워 원본과 같은지 확인 |
| `extract` | 번역 단위 뽑기. 같은 (문장, 문맥 꼬리표)는 하나로 합친다 ⟪패치 3⟫ |
| `pending --lang L` | 번역 메모리에 없는 단위만 약 1만 2천 자씩 묶는다. id는 **짧은 일련번호** `u0001` ⟪패치 6⟫ |
| 번역 AI | 묶음 + 규칙 두 개 → `{"u0001":"…"}` JSON 하나 |
| `check --lang L --in out.json` | 빠진 id, 자리표시·태그, 한글 남음, 앞뒤 공백(중·일 제외), 숫자(만·천 환산 ⟪시리즈 4⟫) |
| `absorb` | 통과한 번역만 메모리에. **실패 id는 `retry` 묶음으로 따로** ⟪패치 4⟫ |
| `merge` | 조립. 꼬리표 데이터 현지화 ⟪시리즈 2⟫ 포함 |

## 2. 토큰 절약 보완 7가지 ⟪패치⟫

### 패치 1 — 번역은 "도구 없는 단발 호출"
- 묶음 하나 = 모델 호출 하나. 도구를 쓰는 에이전트 세션으로 번역하지 않는다. 도구를 부를 때마다 대화 전체가 다시 전송되어 비용이 수 배가 된다(실측: 묶음당 25~35회 호출, 언어당 약 150만 토큰).
- API로 돌릴 수 있으면 **Message Batches API**(약 50% 할인, 24시간 안에 처리)를 쓴다. 급하면 일반 호출.
- 코딩 에이전트밖에 없으면 하위 에이전트에게 **"규칙 2개와 묶음 1개를 읽고, 결과 파일을 한 번 쓰고 끝낸다. 스크립트·명령 실행·다시 읽기 금지"**라고 준다. 호출은 읽기 3회 + 쓰기 1회로 끝난다.

### 패치 2 — 문장은 한 단위로 (제작 규칙, §8)
- 자바스크립트에서 `'…'+x+'…'`로 문장을 이어 붙이지 않는다. **한 문장 = 템플릿 하나** `` `…${x}…` ``. 번역 AI가 문맥 없이도 어순을 정할 수 있다.
- 이미 만든 페이지에 남은 짧은 조각(20자 미만이거나 공백으로 시작·끝나는 조각)에만 `hint`로 앞뒤 40자를 붙인다. 긴 단위에는 문맥을 붙이지 않는다(실측: 문맥이 원문의 4.4배였다).

### 패치 3 — 같은 한국어, 다른 뜻
- 소스에 `/*i18n:문맥*/` 꼬리표를 단다. 예: 면접 판정 `/*i18n:verdict*/'합격'`, 콘크리트 판정 `'합격'`. 단위 id는 (문장, 꼬리표)로 나뉜다. 한국어 화면은 그대로다.
- 꼬리표 없이 두 문맥에 쓰인 짧은 조각(예: `'보다 '`, `'에서 '`)은 번역으로 풀 수 없다. **한국어 문장을 한 덩어리로 다시 쓴다**(패치 2).

### 패치 4 — 실패한 id만 다시
- `check`가 걸러 낸 id만 `retry` 묶음으로 보낸다. 묶음 전체를 다시 번역하지 않는다.
- 숫자 검사의 알려진 오탐은 `check`가 환산해서 거른다(`10만` = 100,000, `2만 4천` = 24,000). 오탐 때문에 재번역하지 않는다.

### 패치 5 — 캐시에 대한 정확한 설명
- 규칙 파일을 묶음마다 **같은 순서로 맨 앞에** 둔다. 이 앞부분이 재사용되는 것은 API에서 프롬프트 캐시를 지정하거나 같은 세션 안일 때뿐이다.
- 채팅 AI에 파일을 첨부하면 대화마다 전부 과금된다. 그래서 규칙 파일은 짧게 유지한다(common.md 1,500 토큰 이하, 언어 파일 300 토큰 이하).

### 패치 6 — 짧은 id, 짧은 출력
- 단위 id는 `u0001`처럼 짧게. 해시 id(12자)보다 출력 토큰이 줄고 베껴 쓰기 오류도 준다. id ↔ 원문 위치 대응표는 도구만 본다.
- 출력은 `{"id":"번역"}`만. 원문 반복·해설·코드 블록 금지.

### 패치 7 — 모델 배분

| 일 | 모델 | 이유 |
|---|---|---|
| 한국어 페이지, 용어 결정, 판정 문장 | 고성능 | 내용 정확도 |
| en · zh · ja 묶음 | 가벼운 모델(Haiku급) | 자료가 많은 언어, 검사가 도구 몫 |
| ru · uz · vi 묶음 | 중간 모델(Sonnet급) | 문법 일치·표기(ʻ ʼ, 성조) 오류가 잦음 |
| retry 묶음 | 원래 모델보다 한 단계 위 | 같은 실수 반복 방지 |
| 검수 | 사람(원어민), 특히 uz · ru · vi | |

## 3. 시리즈 호환 규칙 4가지 ⟪패치⟫

### 시리즈 1 — 파일 배치는 설정으로
- `layout: "folder"` → `en/이름.html` (모델 채용 위원회 1·2차가 이 방식), `layout: "suffix"` → `이름.en.html` (v2 기본, GitHub 웹 업로드용).
- 한 시리즈 안에서는 바꾸지 않는다. 바꾸면 링크·언어 전환·README가 함께 바뀐다.

### 시리즈 2 — 꼬리표(지식 색인) 현지화
- 꼬리표 데이터 블록(`kg-raw`, `kg-ld`, `refs-csl`, `page-meta`)은 **본문 추출에서 뺀다**.
- 대신 `kg-raw` 노드의 `label.ko`·`definition.ko`, 뼈대 주제 이름(`topicLabels`), `page-meta`의 `title`·`series`를 **단위로 뽑아** 같은 번역 메모리로 옮긴다.
- 조립 때 번역판의 `kg-raw`에 `label.{언어}`·`definition.{언어}`를 더한다(한국어·영어는 그대로 둔다). 화면 스크립트는 번역판에서만 `lab()`이 `label[LANG] → label.en → label.ko` 순으로, 정의는 `definition[LANG] → definition.ko` 순으로 쓰게 바꾼다(postReplace). 영어판에서는 이름 옆 영어 보조 이름을 숨긴다.
- `kg-ld`(JSON-LD)는 손대지 않는다.

### 시리즈 3 — 결과 조회 문자열은 번역 금지
- 페이지가 Colab 실행 결과에서 숫자를 찾는 꼬리표 문자열(`'[판정] …'` 등)과 조회 함수의 인자는 옮기지 않는다. 설정 `skipCallArgs: ["outLine","outNums","eNum", …]`, `skipVars: ["CODE_OUT", …]`.
- Colab 코드와 실행 결과는 모든 언어에서 원문 그대로 둔다. 주석만 옮길 때도 결과 줄을 찍는 `print` 문자열은 옮기지 않는다.

### 시리즈 4 — 숫자 검사 환산
- 한국어 큰 수(`만`, `천`)와 서수(`1차`, `2차`, `1등`)는 환산하거나 빼고 비교한다.

## 4. 번역 AI에게 주는 프롬프트

```
rules/common.md 와 rules/lang/{L}.md 를 따른다.
묶음 파일 {L_001.json}의 units를 {언어}로 옮겨 {"id":"번역"} JSON 하나만 출력한다.
glossary의 번역을 그대로 쓰고, 태그·자리표시·엔티티·숫자는 그대로 둔다.
```

에이전트로 돌릴 때(패치 1): `읽기 3회(규칙 2 + 묶음 1) → 결과 파일 쓰기 1회 → 끝. 명령 실행·스크립트·다시 읽기 금지.`

## 5. 검사 (전달 전에 모두 통과)
- [ ] roundtrip 일치 · 모든 묶음 check 오류 0(retry 포함)
- [ ] merge 보고: 번역 없음 0, 화면 한글 0, 스크립트 구문 오류 0
- [ ] 언어 × 페이지 헤드리스: 오류 0, 390 · 1280에서 가로 넘침 없음
- [ ] 자동 전환, `?lang=`, `#섹션` 유지, 편끼리 링크가 같은 언어로
- [ ] 꼬리표: 지식 색인의 이름·정의·주제 이름이 그 언어로, 검색 동작
- [ ] 베트남어 성조, 중·일 줄바꿈 · 원어민 검수 전임을 전달 글에 적기

## 6. 비용 기록 (다음 판을 위한 실측)
묶음마다 `언어, 묶음, 단위 수, 원문 글자, 토큰`을 `work/cost.csv`에 남긴다(`pack.py cost`).

### 첫 적용 실측 (2026-11-01, 2차 공채 꼬리표 · 6개 언어)
| 항목 | 값 |
|---|---|
| 번역량 | 언어당 820단위 · 2만 9천 자 (지식 색인 이름·정의 + 꼬리표 화면 글), 묶음 3개 |
| 호출 | 묶음 18 + 재시도 2, 모두 "읽기 3 + 쓰기 1"(도구 호출 4회) |
| 검사 통과 | 첫 회 4,904 / 4,920 (99.7%). 진짜 실패는 베트남어 숫자 표기 15건(61.8→61,8)과 영어 1건뿐. 재시도 묶음 2개로 끝 |
| 검사기 오탐 (도구에서 고침) | `placeholder` 속성 비교, `2×2만 남는다`의 `2만` 환산, 1~10을 낱말로 쓴 경우 |
| 토큰 | 합계 186만. **호출 1회 고정비 약 5.1만 + 글자당 약 4.7토큰** (회귀 추정) |
| 비교 | 2차 본문 번역(에이전트 루프, 조각+문맥 방식): 글자당 약 7.2토큰(고정비 포함 평균). 글자당 변동비는 약 35% 줄었다 |

**교훈 (패치 1 보강):** 코딩 에이전트의 하위 에이전트는 호출마다 시스템 프롬프트·도구 정의로 **약 5만 토큰의 고정비**가 든다. 1만 2천 자 묶음이면 이 고정비가 비용의 절반이다(1단위 재시도에도 5.7만 토큰이 들었다). 그래서
- **API를 쓸 수 있으면 직접 호출**(가능하면 Batches)한다. 고정비가 규칙 파일(약 1천 토큰)로 줄어 글자당 약 1.5~2토큰까지 내려간다(추정).
- **에이전트밖에 없으면 묶음을 키운다**: `bundleChars` 3만 자(출력 한도 안). 고정비가 비용의 3분의 1 아래로 떨어진다.
- 재시도는 언어를 가리지 않고 **한 묶음으로 모아** 한 번만 부른다.

### 도구 (이 저장소의 구현)
`i18n/pack.py` — `stats` · `pending <L>` · `check <L> <묶음>`(통과분은 `i18n/<L>/pack.json`에 흡수, 실패 id는 `<묶음>r`로, 깨진 JSON은 줄 단위 복구) · `cost`. 조립은 `i18n/build_lang.py <L>`(꼬리표 현지화 포함).

## 7. 설정 추가 키 ⟪패치⟫
| 키 | 뜻 |
|---|---|
| `layout` | `folder` 또는 `suffix` (시리즈 1) |
| `skipCallArgs` | 인자를 옮기지 않을 함수 이름 (시리즈 3) |
| `hintMaxLen` | hint를 붙일 짧은 단위 기준, 기본 20 (패치 2) |
| `bundleChars` | 묶음 크기. API 직접 호출 12000, 에이전트 실행 30000 (6장 실측) |
| `models` | 언어별 번역 모델 (패치 7) |

## 8. 제작 규칙 (ai-lab-explainer 12-5에 더함) ⟪패치⟫
1. 문장은 템플릿 하나: `` `${a}는 ${b}보다 높다` ``. `+`로 잇지 않는다.
2. 조사는 숫자 뒤에서만 도구 함수(`josa`)로 붙이고, 그 함수는 번역판에서 빈 값을 낸다.
3. 같은 한국어가 다른 뜻이면 `/*i18n:문맥*/` 꼬리표.
4. 결과 조회 문자열은 `[꼬리표] …` 형식으로 시작해 도구가 알아보게 한다.
5. 화면에 쓰는 데이터(이름표·범례)는 배열에 문장 단위로 둔다.
